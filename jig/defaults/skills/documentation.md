# Documentation

- Update README.md — do NOT overwrite it, edit existing sections or add new ones
- README should include: project description, installation, usage, development setup
- Add docstrings to all public functions, classes, and modules
- Use Google-style docstrings for Python
- Keep docstrings concise — describe what, not how
- If the project has a `docs/` directory, update relevant files there
- Include code examples in docstrings where they clarify usage
